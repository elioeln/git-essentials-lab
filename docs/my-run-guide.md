\# Run guide



\## Prerequisites

\- Git 2.23 or later

\- JDK 17 or later (both `java` and `javac`)

\- Python 3.9 or later



\## Run the demo

From the repository root, run:

&#x20;   python3 run.py demo

(On Windows, `python run.py demo` works if `python3` is not available.)



\## What the demo does

The demo initializes the catalog, demonstrates book loans for students and faculty members, checks borrowing limits and overdue fees, and prints transaction receipts.
